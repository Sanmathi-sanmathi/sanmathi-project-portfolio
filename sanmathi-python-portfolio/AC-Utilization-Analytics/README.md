# AC Utilization Analytics

## What This Project Does

This tool analyzes vehicle AC performance data and generates visualizations for AC utilization and compressor behavior.

It helps understand AC usage patterns across multiple vehicles using distribution charts and statistical analysis.

## Input

CSV file containing:

- VIN
- AC Utilisation (%)
- Overall Compressor Duty Cycle (%)
- AC Utilisation in High Mode (%)
- AC Utilisation in ECO Mode (%)

## Processing

- Clean and validate data
- Categorize utilization ranges
- Calculate vehicle distributions
- Generate statistical summaries
- Create analytical charts

## Output

Charts for:

- AC Utilisation Analysis
- Compressor Duty Cycle Analysis
- High Mode Utilisation Analysis
- ECO Mode Utilisation Analysis
