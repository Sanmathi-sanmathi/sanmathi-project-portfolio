# Ollama Chat Application

## What This Project Does

This application provides a simple AI chatbot interface powered by Ollama and LangChain.

Users can ask questions through a web interface, and the application generates real-time responses using a locally running Ollama model.

## Input

- User Questions
- Text Prompts

## Processing

- Accept user queries
- Send requests to Ollama
- Generate AI responses
- Maintain chat history
- Display conversation in real time

## Output

- AI-generated responses
- Chat history within the application

## Features

✅ Local AI Chatbot

✅ Ollama Integration

✅ LangChain Integration

✅ Chat History Management

✅ Streamlit Web Interface

✅ Real-Time Responses

## Tech Stack

- Python

- LangChain
- Ollama
