# Vehicle Trip Distribution Analysis

## What This Project Does

This solution analyzes vehicle trip data and applies the Empirical Rule (68-95-99.7 Rule) to understand the distribution of vehicle running hours and running distance.

The tool automatically calculates statistical boundaries and generates visualization charts to identify normal operating ranges and unusual vehicle behavior.

## Input

CSV file containing:

- Daily Running Hours
- Daily Running Distance

## Processing

- Load trip data
- Calculate Mean and Standard Deviation
- Apply Empirical Rule (1σ, 2σ, 3σ)
- Generate probability distribution plots
- Visualize normal operating ranges

## Output

Two analytical charts:

- Running Hours Distribution
- Running Distance Distribution

## Business Value

✅ Understand vehicle usage patterns

✅ Identify abnormal trips

✅ Support fleet performance analysis

✅ Enable data-driven decision making
