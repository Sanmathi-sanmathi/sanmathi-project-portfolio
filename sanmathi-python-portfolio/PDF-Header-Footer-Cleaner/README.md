# PDF Header Footer Cleaner

## What This Project Does

This application helps users remove unwanted headers and footers from PDF documents and optionally delete selected pages.

Users can upload a PDF, preview the detected header and footer areas, clean the document, and download the processed PDF.

## Input

- PDF Documents

## Processing

- Detect header and footer content
- Preview header/footer regions
- Remove unwanted header and footer elements
- Delete selected pages
- Generate a cleaned PDF

## Output

```text
Cleaned PDF

PDF with selected pages removed
```

## Features

✅ PDF Upload

✅ Header/Footer Detection

✅ Header/Footer Removal

✅ Visual Preview
