# Histogram Report Generator

## What This Project Does

This automation tool analyzes histogram data from a CSV file and generates a consolidated frequency report.

It calculates the occurrence count of values across multiple parameters and exports the results into a structured CSV report.

## Input

CSV file containing:

- Torque Histogram
- Throttle Histogram
- Engine Speed Histogram
- Vehicle Speed Histogram

## Processing

- Reads histogram data
- Calculates frequency counts
- Combines all histogram ranges
- Generates a consolidated report

## Output

CSV report containing:

- Value Range
- Torque Count
- Throttle Count
- Engine Speed Count
- Vehicle Speed Count

## Tech Stack

- Python
- Pandas
- NumPy
